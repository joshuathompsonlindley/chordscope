# Chordscope

Drop a MIDI part exported from your DAW (Logic, Ableton and the like) and Chordscope names its chords and estimates the
key. It shows the key and a table with each chord's notes and how it reads in each candidate key. Hover the key to see how sure the estimate is.

## Run it

```sh
npm install
npm run dev           # dev server
npm test              # unit, page and clip tests
npm run check         # type-check, lint, formatting and tests: run before committing
npm run build         # type-check, then build to dist/
npm run format        # rewrite files with Prettier
```
